# Emissions factors

A small, honestly-sourced table, not a comprehensive database. Use a row where
one exists. **Where a factor you need isn't in this table, estimate it and say
plainly that you're estimating** — don't stall the report chasing precision
this table was never meant to provide, and don't quietly present an estimate as
if it came from here.

All figures are approximate published averages, not measurements of any
individual's actual usage — treat them as ranges even where a single number is
given below.

## Flights (per passenger, per hour flown, economy class, includes radiative forcing uplift)

| Flight type          | kg CO2e / hour | Source                                  | Year |
| --------------------- | -------------: | ---------------------------------------- | ---- |
| Domestic               |            155 | UK DEFRA/BEIS GHG Conversion Factors     | 2023 |
| Short-haul (<3h)       |            110 | UK DEFRA/BEIS GHG Conversion Factors     | 2023 |
| Long-haul (>6h)        |             90 | UK DEFRA/BEIS GHG Conversion Factors     | 2023 |

Long-haul is lower per hour because takeoff/landing (the most fuel-intensive
part) is a smaller share of a longer flight.
